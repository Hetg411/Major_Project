# Wanderlust – Hotel Finder Web App

A full-stack hotel discovery platform where users can explore hotels by price, amenities, and location, and hotel owners can manage their own listings.

## Features
- Browse hotels with details such as price, amenities, and location
- Google Maps API integration for location-based hotel exploration and navigation
- Secure user authentication and role-based authorization (guest vs. owner)
- Hotel management module — owners can add, edit, and delete their listings
- Responsive web interface

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend/Templating:** EJS, JavaScript, HTML, CSS
- **APIs:** Google Maps API

## Getting Started

### Prerequisites
- Node.js and npm installed
- MongoDB instance (local or Atlas)
- Google Maps API key

### Installation
```bash
git clone https://github.com/Hetg411/Major_Project.git
cd Major_Project
npm install
```

### Environment Variables
Create a `.env` file in the root directory with:### Run the App

## Usage
1. Sign up / log in.
2. Browse and search hotels by price, amenities, and location.
3. View hotel locations and navigate using the integrated map.
4. Owners can log in to add, edit, or delete their hotel listings.
